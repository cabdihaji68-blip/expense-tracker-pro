# Expense Tracker PRO 💰

A modern, responsive web application designed to help users efficiently track and manage their personal income and expenses.

## 🚀 Key Features
- **Dashboard:** Automatically calculates and displays total income, total expenses, and net balance in real-time.
- **Transaction Form:** Allows users to input transaction descriptions, amounts, types (Income/Expense), categories, and dates with data validation.
- **Transaction History:** Displays all recorded transactions dynamically with individual delete buttons.
- **Search & Filter:** Enables users to instantly search for specific records or filter them by income and expense types.
- **Local Storage:** Persists user data locally in the browser so that records are not lost upon page refresh or browser closure.

## 🛠️ Technologies Used
- **HTML5** - Structuring the web application content
- **CSS3** - Styling, layout, and responsive design (Flexbox/Grid)
- **JavaScript (ES6+)** - Core logic, array methods (`filter`, `reduce`), and DOM manipulation
- **FontAwesome** - Modern UI icons
